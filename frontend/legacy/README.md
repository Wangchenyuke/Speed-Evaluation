# Legacy Static Prototype

This folder stores the original static HTML/CSS prototype for SPEED.  
It will remain available as a visual reference while the new React/Next.js front-end is implemented.

Files include:
- `index.html`, `search.html`, `submission.html`, `login.html`, `register.html`
- `styles.css`, `auth.js`, `data.js`

All new development should happen inside the root `frontend` app (to be initialized with Next.js).
